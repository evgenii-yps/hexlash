# Автономные копии деки — образец для Claude Design

Копия страницы `hexlash.com/deckinvestors` одним HTML-файлом: открывается двойным щелчком, без интернета.
Шрифты (Saira Condensed 700/800/900, JetBrains Mono 400–700 латиница+кириллица), знак, постер — внутри файла.

| Файл | Что внутри |
|---|---|
| `deck_export_full.html` | с видео зала (720p, 6,9 с, петля) |
| `deck_export_light.html` | вместо видео постер с подписью «ЗДЕСЬ ВИДЕО ЗАЛА 6,9 с, петля» |

Это **выгрузка, не источник правды**: страницу сайта (`public/deckinvestors/index.html`) скрипт не меняет.
Пересобрать после правок деки: `python3 docs/deck-export/build_export.py` (сеть нужна только за шрифтами).

Отличия копии от сайта (намеренные): видео всегда 720p (на сайте компьютер получает 1080p);
ссылка «ПЕРЕЙТИ/GO» абсолютная (`https://hexlash.com/play/gate`); убраны `og:image`/`twitter:image` (картинка превью).
