# Дека: правки ревью (TZ_deck_review_fixes_v1)

- `before/`, `after/` — снимки JPEG: `{en|ru}-{1280x650|1440x900|390x844}-{top,s01,s02,s03,s04,s08,s12,s13,s21,finale,foot}`, оглавление на ширине 1200 — `{en|ru}-1200-toc`.
- `landing/` — шапка лендинга до/после (позиции пунктов совпадают до точки, файлы лендинга не менялись).
- `modes/` — «уменьшить движение», выключенный JavaScript, подчёркивание текущей главы.
- `text-diff.txt` — сверка текстов по всем узлам (было → стало), построена скриптом.
