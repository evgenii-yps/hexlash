# Свой источник случайности для боя (заход 1 плана завершения баланса, 02.10.2026)

База: `main` = `92ff8c27`. Откат — этот коммит целиком (`git revert`), либо `92ff8c27`.

## Проблема
Боец (`buildFighter`), поле боя (`battleField`) и обход преград (`coverNav`) брали числа из общего
`Math.random` — того же, что берут дым легенды, пыль, текстуры. Любая правка вида арены сдвигала ход боя в игре;
регрессии считают бой без сцены и этого не видели. Нарушало §3.11 ТЗ легенды.

Доказательство до правки (`scripts/bout-random-isolation.mjs`, новый): 144 боя с «шумом картинки» между шагами —
**144 разошлись**, у части сменился победитель.

## Где бой брал случайность (полный перечень)
| Файл | Мест | Что решает |
|---|---|---|
| `src/scene/buildFighter.js` 🔒 | 45 | все решения бойца: промах, уворот, ритм, дуга, чтение врага, выбор приёма, разброс урона |
| `src/scene/battleField.js` | 2 | цель у RAIDER «наугад»; жребий короны на сторону |
| `src/scene/coverNav.js` | 1 | зерно точки подмены при обходе преград |

Картинка (`legendPresence`, `arenaTextures`, `buffItems`, `*Wander`) осталась на `Math.random` — это допустимо.
Не тронуто осознанно: `rollDie` (бросок кубика баффа — одна функция «под сервер», решение 22.09), `foeCompose` /
`collapseRun` (уже принимают `rnd`, считаются до боя).

## Правка
Новый `src/scene/boutRandom.js` (`createRng`, `freshSeed`, mulberry32 — тот же, что зажимает зерно в замерах).
Каждый участник боя заводит свой генератор один раз: зерно берёт из общего потока в момент создания, дальше
с ним не связан. В игре зерно случайное → бои, как и раньше, разные. В замерах зерно повторяется → бой
повторяется шаг в шаг. Все три фабрики принимают необязательный `rng`.

## Результат
- `scripts/bout-random-isolation.mjs`: **144 из 144 боёв совпали** (было 0 из 144). Скрипт — постоянная страховка:
  код выхода ≠ 0, если картинка снова начнёт двигать бой.
- Бой повторяется бит в бит (двойной прогон — одна сумма).
- Сборка проходит.
- Статистика не изменилась (2400 боёв до/после): медиана 45.7 → 45.5 с, таймаутов 0; доли побед ядер
  49/52/50/48 → 50/49/54/48 (разброс в пределах шума, 600 боёв на ядро).
