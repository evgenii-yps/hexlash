Всё остальное сверено по пунктам правила §4: «hits harder» — только там, где есть рамп силы или добавка `strikePower`;
«tougher / guard» — только там, где есть `toughness` или `blockMitigation`; «breaks guards» — только там, где есть `blockPenetration`
(для заряженного — `chargePen`); «strongest / hardest / biggest» — сверено внутри грани по числам.
Все CHARACTER, кроме перечисленных выше, соответствуют наклону выбора намерения (`TAG_LEANS`) и сдвигам осей.

## §7 — читает ли думающий боец имена или тексты кристаллов

**Нет.** Портрет бойца для модели собирается в `services/command.js` (`legendPortrait`) из двух вещей: фраза ядра (`core.manner`)
и фраза каждого зажжённого кристалла из `facetReadout.js` (`facetPhrase`: «Harder hits», «Pierces guard», «Slips more»…) —
то есть из чисел данных, а не из `crystalTexts.js`. Замена текстов на экране модель не затрагивает. Имена (`face.name`) модель не видит.
`crystalTexts.js` читают ровно три места показа: `ForgeCore.vue`, `ForgePanel.vue`, `SparView.vue` (+ служебные скрипты замеров в `scripts/`).
