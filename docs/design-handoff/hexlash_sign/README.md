## Чем этот эталон является и чем не является

**Задаёт:** пропорции и толщину букв, характер фаски и блика, форму и плотность облака, силу и холод свечения, характер мерцания.

**Не задаёт:** положение вывески в мире, её размер в кадре, дистанцию до камеры, яркость после тумана. Эти числа меряются в коде и уже подобраны замерами — из макета их брать нельзя.

## Жёсткие правила

- Шрифт: **Saira Condensed 900**, заглавные. Другого начертания нет.
- Цвет букв: `#F6F4F6`. Фон мира: `#08080A`.
- Свечение **холодное белое**. Розового `#FF0069` в этом объекте нет нигде — ни в буквах, ни в ореоле, ни в облаке. Розовый принадлежит только действию (кнопка FIGHT, ядро бойца).
- Сила свечения средняя: вывеска обязана быть заметно тусклее кнопки FIGHT — она не самый яркий объект на экране.
- Материал матовый, гранёный low-poly. Металл присутствует только как фаска на ребре буквы и один блик по ней. Ни глянца, ни стекла, ни неоновой трубки.
- Облако холодное, само не светится — выглядит подсвеченным буквами; пик его яркости ниже пика яркости букв.
- Слово **стоит** на дымке, утоплено на **1/10 высоты букв**. Верхние две трети чистые: клочьев дымки перед ними нет.
- Никакой подложки, рамки, плашки, черты под словом — опору даёт только облако.
- Если слово не влезает в кадр целиком — оно не показывается вовсе. Обрезанной вывески не бывает.
- Плоский знак-гекс из шапки интерфейса — другой объект: он не светится. Не использовать как образец.

## Числа для движка

**Буквы**
- межбуквенное: +1,5 % em (на 900 в конденсе меньше — буквы слипаются)
- глубина выдавливания: ≈ 7 % высоты капители
- фаска: ≈ 1 % высоты буквы, один блик по верхнему ребру
- фронтальная грань: почти ровный `#F6F4F6`, лёгкое осветление верхних 40 %, притемнение нижних 28 % (`#dfe3e9`)
- боковая стенка: матовый градиент `#a9aeb8 → #545a63`

**Облако**
- сплюснутый эллипсоид, ширина **1,6 × ширины слова**, высота **1,25 × капители**
- ядро на 60–72 % высоты тела, плотнее в середине, мягче к краям, резких кромок нет
- поверх ядра 4 несимметричных клока — верхний контур не должен быть прямой линией
- в просветах между буквами плотность та же, что под буквами (задняя пелена сплошная)
- в профиль: «живот» в середине по глубине, дымка есть и перед буквами, и за ними
- палитра дымки: `rgba(214,228,244,…)` / `rgba(198,214,234,…)` / `rgba(182,202,224,…)`, максимальная альфа ядра ≈ 0,52

**Мерцание** (то же, что у заголовка HEXLASH на лендинге)
- цикл 13 с, два события за цикл (≈ на 2,3 с и ≈ на 7,9 с)
- просадка пятью ступенями: 1 → 0,86 → 0,72 → 0,58 → 0,49 → 0,40
- дно 0,4, удержание ≈ 0,23 с, возврат ≈ 0,3 с
- гаснет **только ореол**. Буквы не темнеют и не двигаются

**Размер (главный вывод)**
- 100 % — читается как вывеска над воротами
- 60 % — **не работает**: облако сжимается до кромки, ореол перестаёт отделять слово от тумана, объект читается подписью
- граница ≈ **72 %**, ниже 70 % ломается устойчиво
- рекомендация: 72–75 %, остаток по перекрытию наставника над плитой FORGE добирать другими рычагами (горизонталь и высота, по замерам 14.09.2026, не решают)

## Как читать кадры

1. **Геройский** — основной эталон: холод свечения, отсутствие розового, погружение на 1/10.
2. **Три четверти ≈30°** — толщина буквы, боковая стенка, фаска и блик.
3. **Облако в профиль** — слово стоит ребром: дымка перед и за ним, «живот» в середине, края растворяются.
4. **Раскадровка мерцания** — пять ступеней, подписан процент.
5. **Проверка размера** — 100 % и 60 % на одном фоне.
6. **Композиция 844×390** — слово влезает целиком с запасом, платформа внизу только силуэтом.

## Твики в эталоне

В панели твиков: сила свечения (0,4–1,6), плотность облака (0,4–1,5), глубина погружения букв (0,02–0,35 высоты капители). Значения по умолчанию — 1 / 1 / 0,1 — и есть эталон; твики нужны только для сверки с движком.
