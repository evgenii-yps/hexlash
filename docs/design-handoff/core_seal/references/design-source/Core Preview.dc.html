Плотный раздел деки

Проверка читаемости: на деке фон идёт на половинной яркости, мерцание почти не заметно, контраст текста к фону сохраняется выше 4.5:1.

Что изменено против эталона

  • Размытие (feGaussianBlur) на сторонах контура заменено широкой полупрозрачной обводкой — то же свечение, но без пересчёта фильтра на каждом кадре мерцания.
  • Мерцает группа-обёртка стороны (одна прозрачность на элемент), остальная фигура статична; при «уменьшить движение» анимация выключается правилом медиазапроса.
  • Ветки перерисованы как цельные сужающиеся клинья без ромбиков внутри; сердце — плоский шестиугольник в рамке с тонким внутренним кольцом.
  • Белого в фигуре нет: светлые места — цвет раздела и тёмный серо-лиловый.
  • Горящие грани позже: каждую ветку можно разбить по длине на пять сегментов-полигонов и наливать светом снизу вверх, меняя только их прозрачность — форма и разметка уже это позволяют.
