# docs/design-handoff

## `hexlash_mark/` — живой

Эталон знака Hexlash: готовые картинки в двух отрисовках под разные размеры,
правила цвета, охранного поля и минимального размера. Геометрии и вектора в
пакете нет — знак растровый. Из пакета **читает сборка**:
`scripts/sync-brand-icons.mjs` раскладывает готовые рендеры в `public/` и
пересобирает `favicon.ico`.

Трогать по правилам из `hexlash_mark/README.md`. Отрисовка в приложении —
`src/components/brand/hexlashMark.js`.

## `hexlash_sign/` — снят с экрана (30.09.2026)

Эталон вида ОБЪЁМНОЙ вывески HEXLASH, которая стояла в коридоре между домом и
плитами режимов. Шесть кадров + те же числа машинно (`params.json`).

⚠️ **Объёмная вывеска убрана из игры целиком** (решение владельца 30.09.2026):
код, облако под словом, правило подгонки и материал `MATERIALS.sign` удалены, в
мире её больше нет. Папка оставлена на диске как память о том, каким был вид, —
это не источник правды для кода, которого нет. Мерцание `src/data/signFlicker.js`
осталось: им пользуется надпись на лендинге (`LandingHero.vue`).

Если вывеску когда-нибудь вернут, пересобирать её придётся заново по этому
эталону; прежняя реализация — в истории git до коммита «remove 3D HEXLASH sign
from home».

## `_archive/` — история, не источник правды

Эталоны экранов, по которым интерфейс уже перенесён: дом, магазин, выбор
режима, выбор зала, вторичные кнопки.

С Дизайн-системой v1.0 (03.09.2026) источник значений один —
`src/styles/tokens.css` и `src/data/sceneTokens.js`. Эталоны оставлены как
запись того, откуда взялась композиция экрана, но **их числа больше не
действуют**: где эталон расходится с токенами, прав токен.

Переносить новое «как в эталоне» нельзя — числа в них до-системные.
