# Handoff: знак Hexlash (brand mark + иконки)

## Overview
Новый знак бренда Hexlash: боец в боевой стойке, вписанный в шестиугольник. Знак заменяет прежний гекс с росчерком **везде сразу** — favicon/вкладка, верхняя панель игры, экран загрузки, лендинг, иконка приложения.

Пакет содержит готовые векторные и растровые файлы + точную геометрию, чтобы знак можно было при необходимости воспроизвести в коде, а не пересобирать из картинки.

## About the Design Files
Файлы в `assets/` — **готовые продакшн-ассеты** (SVG и PNG), их можно подключать как есть.
Файл `preview.dc.html` — **дизайн-референс** (лист приёмки, показывающий знак во всех размерах и контекстах). Это не продакшн-код: не копируйте его разметку в приложение, используйте только как справку о том, как знак должен выглядеть и где применяется.

## Fidelity
**High-fidelity.** Геометрия финальная и утверждена. Цвета, пропорции и пороги переключения отрисовок — точные, не приблизительные.

## Жёсткие правила бренда
- Знак монохромный: **#F6F4F6** на фоне **#08080A**.
- Фирменный розовый **#FF0069** в знаке не используется никогда.
- Нет свечения, блума, теней, градиентов, объёма, обводок-эффектов.
- Пластика огранённая (low-poly): прямые срезы и углы, никаких скруглений и анатомии.
- Форму знака не менять, слово HEXLASH не перенабирать другим шрифтом.

## Три отрисовки — какую где брать
Знак существует в трёх РАЗНЫХ отрисовках, нарисованных под свой диапазон размеров. Масштабировать одну вместо другой нельзя.

| Отрисовка | Диапазон | Файл | Что в ней |
|---|---|---|---|
| A — полная | ≥ 64px | `hexlash-mark.svg` | Полный набор плоскостей: у каждой конечности две грани с общим ребром в суставе |
| B — упрощённая | 28–48px (24px допустим) | `hexlash-mark-compact.svg` | Обводка тоньше относительно размера, просветы больше, суставы сведены к одному слому |
| C — мелкая | ≤ 20px | `hexlash-mark-micro.svg` | Нарисована пикселями на сетке 16×16: только целые координаты, ни одной диагонали, все линии и просветы ровно 1px |

Правило переключения в коде: `size >= 64 ? A : size >= 24 ? B : C`. Между 20 и 24 px берите C — узнаваемость важнее точности.

### Иконка приложения
`icon-maskable-512.png` — 512×512, плитка #08080A, знак занимает 80% ширины по центру. Именно этот файл идёт как `purpose: "maskable"` в web app manifest: запас нужен, чтобы круговая обрезка на телефоне не срезала углы гекса.

### Геометрия
`geometry.json` — все координаты трёх отрисовок:
- `A_HEX_OUT` / `A_HEX_IN` — внешний и внутренний контуры гекса отрисовки A (кольцо задаётся двумя контурами, внутренний идёт в обратном направлении → `fill-rule: nonzero` даёт дырку);
- `A_FIG` — 10 полигонов фигуры A (голова, торс, 2×2 плоскости рук, 2×2 плоскости ног);
- `B_HEX_OUT` / `B_HEX_IN` / `B_FIG` — то же для B (8 полигонов);
- `C_ALL` — отрисовка C как список пиксельных прямоугольников `[x, y, w, h]` на сетке 16×16.

Формат точек — строки `"x,y x,y ..."`, как в SVG `<polygon points>`.

## Пропорции (для воспроизведения в коде)

**A, поле 64×64.** Гекс 48 в ширину × 56 в высоту, по центру (поля 8 по горизонтали, 4 по вертикали). Толщина обводки 3.6 = **7.5% ширины гекса**. Фигура 34.1 × 36.1 = **71% ширины и 64% высоты гекса**. Голова-шестиугольник 12.5 в ширину = **26% ширины гекса**. Минимальный просвет между телом и гранью — 3.3 = **6.9% ширины гекса**.

**B, поле 48×48.** Гекс 40 × 46. Обводка 2.8 = **7.0% ширины гекса**. Фигура 25.2 × 28.4 = **63% ширины и 62% высоты гекса**. Голова 9.4 = **23.5% ширины гекса**. Просвет тело↔грань — не меньше 8% ширины гекса.

**C, сетка 16×16.** Гекс 12 × 16px, кольцо 1px, углы ступенями по 2px (гекс сознательно спрямлён — на этом размере это незаметно, а чёткость важнее). Фигура 8 × 9px: голова 4 × 2px, руки — две полосы 2 × 3px, корпус 2px с просветами по 1px, бёдра 4 × 2px, ноги — два блока 2 × 2px. Все просветы 1px. Размер 20px = то же ядро 16px с полем 2px по кругу (не масштабирование!).

## Лок-апы и охранное поле
- Минимальное расстояние от знака до любого другого контента — **25% высоты знака** (при 64px это 16px).
- Горизонтальный лок-ап: зазор знак↔слово **37.5% высоты знака**; кегль слова = 72% высоты знака.
- Вертикальный лок-ап: зазор **50% высоты знака**.
- Слово: **Saira Condensed 700**, заглавные, разрядка **0.22em** в горизонтальном лок-апе и **0.30em** в вертикальном. Начертание не менять.
- ⚠️ В SVG-лок-апах слово пока задано как `<text>` с запасным стеком шрифтов и фиксированной `textLength` (чтобы строка не обрезалась без шрифта). Если Saira Condensed не подключён в приложении — либо подключите его, либо соберите лок-ап из `hexlash-mark.svg` + текстового узла в вёрстке.

## Что подключить в вебе
```html
<link rel="icon" type="image/png" sizes="16x16" href="/mark-16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/mark-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/mark-180-tile.png">
<link rel="manifest" href="/site.webmanifest">
```
manifest:
```json
{
  "icons": [
    { "src": "/mark-192-tile.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/mark-512-tile.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```
`.ico` в пакет не входит — соберите его из `mark-16.png` и `mark-32.png` на своей стороне.

В интерфейсе знак вставляйте инлайновым SVG и красьте через `color`, а не `fill`:
```css
.mark { color: #F6F4F6; }
.mark--on-light { color: #08080A; }
```

## Продуктовые решения (уже приняты)
- Анимация «бегущий боец» на экране загрузки **отменена** — на загрузке статичный знак (отрисовка A, крупно).
- Новый знак заменяет старый **везде сразу**: вкладка, панель игры, лендинг, иконка приложения. Двух знаков в продукте одновременно быть не должно.
- Цветных версий знака и версий под цвета ядер не существует. Если нужен знак на цветном фоне — только #F6F4F6 или #08080A поверх.

## Чего НЕ делать
- Не масштабировать A на мелкие размеры вместо B/C.
- Не превращать залитые контуры обратно в `stroke` — при масштабировании толщина поедет.
- Не добавлять свечение, тени, градиенты, скругления.
- Не перекрашивать знак в #FF0069.
