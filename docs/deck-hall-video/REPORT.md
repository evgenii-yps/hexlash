# Окно «Зал с бойцами» в деке (раздел 03) — отчёт этапа 1

ТЗ: `TZ_deckinvestors_hall_video_v1`. Выбран вариант A (зал FORGE, легенда над залом + спуск к грушам).

- Файлы: `public/deckinvestors/hall-loop-1080.mp4` (2,30 МБ), `hall-loop-720.mp4` (1,14 МБ), `hall-poster.jpg` (26 КБ).
- Вес HTML деки: 317 464 → 321 477 байт (+4,0 КБ).
- Проверки (`shots/`, скрипт — одноразовый, в репозиторий не кладётся): 62 из 62.
  Три ширины (1440 / 1024 / 390) × RU и EN: до прокрутки и далеко от раздела видео не запрашивается;
  за экран до раздела запрашивается (≤700 → 720p, иначе 1080p); в кадре играет, вне кадра — пауза;
  подпись верная; горизонтальной прокрутки нет. Смена языка, «уменьшить движение», сломанный путь,
  запрет автозапуска (имитация энергосбережения iOS → играет после касания).
- Оговорка: встроенный Chromium в песочнице не умеет H.264, поэтому в прогоне тело `.mp4` подменялось
  на WebM из тех же кадров (только в тесте). Логика страницы проверена целиком, а кодек H.264 (High@4.1,
  yuv420p, faststart, без звука) проверен только по `ffprobe`; на живом Safari/Chrome — глазами владельца.
- При сломанном пути браузер сам пишет в консоль строку про 404 — это не ошибка скрипта, подавить нельзя.
- Шрифты Google в песочнице недоступны (ошибка сертификата прокси) — к правке не относится.
