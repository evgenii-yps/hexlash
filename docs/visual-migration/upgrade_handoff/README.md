# HEXLASH — Экран прокачки · эталон-хэндоф

Drill-down бойца: **ядро → кристалл → грань**. Игрок уже выбрал ядро на прошлом
экране; здесь он шлифует грани и жмёт **«В бой»**. Это флагман.

Чистый **HTML / CSS / vanilla JS**, без сборки и зависимостей. Шрифты — Google Fonts
(`Saira Condensed`, `JetBrains Mono`). Готов к порту на **Vue 3**.

> **Контент — заглушки.** Имена кристаллов/граней, числа, лимиты помечены как рабочие
> (`Грань 01…`, `КОРКА`, `2/3`). Их правит геймдизайн. Здесь — оболочка и язык.

## Иерархия (3 уровня · всё играется от ядра)

| Уровень | Что | data-level |
|---|---|---|
| **Ядро** | в центре, единственное свечение. Тап → раскрываются кристаллы | `core` |
| **Кристалл** | у ядра их несколько (ветви). Раскрываются по радиусу из центра (спицы). На каждом — счётчик зажжённых граней `lit/limit`. Тап → его грани | `crystal` |
| **Грань** | узел прокачки. Состояния `lit` / `open` / `locked`. Панель снизу, ядро и прочие кристаллы рецессируют | `face` |

Глубина — через `[data-level]` на `.screen` + CSS-переходы `transform / opacity / blur`.
Возврат — кнопка `.back` + крошки **Ядро · Кристалл · Грань** (активный — в цвете ядра).

## Механика «вкачать всё нельзя» (двойной ограничитель)

1. **Общий пул очков ядра** — `RESOURCE = 5` (заглушка). Делится между всеми кристаллами.
   Виден внизу на уровнях ядро/кристалл и в панели граней.
2. **Личный лимит кристалла** — `limit` (заглушка 2–3). Кристалл не даст зажечь больше.

Грань зажигается только если `lit < limit` **И** есть свободные очки. Иначе доступные
грани помечаются `лимит` / `нет очков` и трясутся при тапе. **Зажёг одно — погаси другое.**

## Дисциплина (планка, не нарушать)

- **Тёмный фон.**
- **Один акцент = цвет выбранного ядра.** Весь экран темится в него через одну
  переменную `--core` (+ производные `--core-sup/-dim/-faint/-ink`). Кнопка «В бой» и
  все ключевые акценты — в этом же цвете. Палитра ядер:

  | id | имя | `hue` |
  |---|---|---|
  | `natisk` | Натиск | `#FF3344` |
  | `nalet`  | Налётчик | `#FFA526` |
  | `skala`  | Скала | `#2ED6B0` |
  | `zasada` | Засада | `#9461FF` |

  Свитчер внизу (`// демо · свап --core`) — **только для хэндофа**: показывает, что весь
  экран меняет цвет одной переменной. В игре ядро уже выбрано на прошлом экране.
- **Одно свечение на экран = ядро в центре** (`.core-node .glow`, мягкий блум). Кристаллы и
  грани — **плоские**, без ореола (зажжённая грань = плоская заливка `--core-faint`).
- **Шрифты:** `Saira Condensed` — текст/заголовки/CTA; `JetBrains Mono` — счётчики, цифры,
  лейблы, крошки.
- **Минимализм**, не киберпанк-перегруз.

## Контракт для порта на Vue (структура 1:1)

### Данные (`data.js`) → props / store
- `CORES` — `[{ id, ix, name, hue, sup, manner }]`. **`id` не менять** (`natisk/nalet/skala/zasada`).
- `CRYSTALS[coreId]` — `[{ id, name, limit, faces:[{ id, name, state }] }]`.
  Состояния грани `state ∈ 'lit' | 'open' | 'locked'` — **имена не менять**.
- `RESOURCE` — общий пул очков ядра.

### Чистые функции геометрии (`data.js`) → переносятся как есть
- `hexPts(cx,cy,r)` — точки pointy-top гекса.
- `coreSVG(kind,{seed})` — SVG ядра (силуэт граней — в `FACETS[kind]`).
- `shardSVG(litRatio, uid)` — гекс кристалла, заливка снизу по доле. `uid` — ключ `<clipPath>`
  (в Vue передать `id` кристалла, чтобы id были уникальны).
- `faceHex()` — гекс грани.
- `radial(n, r)` — раскладка `n` кристаллов по кругу радиусом `r`.

### Логика (`upgrade.js`) → методы компонента
- `setLevel(l)` — `'core' | 'crystal' | 'face'`. В Vue — **реактивное поле** вместо
  `data-level`; CSS-селекторы `.screen[data-level="…"]` заменить на `:class`.
- `openCrystal(id)` / `goCrystals()` / `goCore()` — навигация.
- `toggleFace(cr, el)` — зажечь/погасить с проверкой `limit` + `RESOURCE`.
- `spentTotal()` / `freePts()` — производные ресурса (в Vue — `computed`).
- Состояние правится в `state` (глубокая копия `CRYSTALS`) — в Vue это стор.

### Прочее
- Холст экрана **430×932** масштабируется под вьюпорт (`fit()` — `Math.min(...)`). В Vue —
  обернуть в компонент-сцену, логику фита оставить.
- Контекст ядра приходит с экрана выбора (заглушка `coreId='skala'`). В Vue — стор/роут-параметр.
- Шрифты — на проде вынести на self-host woff2, `font-display:swap`.

## Чего НЕ делать

- ❌ Второе свечение. Светится только ядро; кристаллы и грани — плоские.
- ❌ Больше одного акцента на экран. Всё ключевое — в `--core`.
- ❌ Менять `id` ядер или имена состояний граней (`lit/open/locked`) — они уходят в стор.
- ❌ Перегруз «киберпанком»: лишние свечения, рамки, шум.
