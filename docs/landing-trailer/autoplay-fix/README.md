# Автозапуск фона лендинга при запрете (iPhone, энергосбережение)

Проверка в эмуляции: `play()` у фонового видео отклоняется (как iOS в режиме энергосбережения), пока не было касания.
Реальный iPhone с включённым энергосбережением проверяет владелец.

- `1-normalnyj-rezhim.mp4` — самозапуск разрешён: фон играет сам (как раньше).
- `2-zapret-kasanie-fon-poshel.mp4` — запрет: заставка; прокрутка — запрет остаётся; касание — фон пошёл.
- `3-povorot-pri-zaprete.mp4` — запрет + поворот: новый файл петли, заставка спокойная; касание — идёт, удар слова синхронен; поворот обратно.

Измерения: при запрете `is-on` выключен, переменные знака/слова пусты (эффектов вхолостую нет); синхронность кадров петли с эффектами после запуска — 39 кадров в окне, 0 расхождений; «уменьшить движение» — видео не создаётся; компьютер — играет сам.
