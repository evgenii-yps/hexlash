# Знак в конце круга петли улетает в шапку — приёмка (ТЗ v2, 03.10.2026)

Код: `src/data/heroLoop.js` (время и чистая функция `loopFx`), `src/components/landing/LandingHero.vue`
(полёт и вспышка), `landing.css` (`.hero-mark`). Стенд: `scripts/landing-mark-flight-e2e.mjs`
(боевая сборка + `vite preview`, видео ставится на паузу на нужном времени кадра, 97 проверок).

## Время на круге (пре-флайт п.4)
Удар 16.45 с, конец файла 18.7 с — после удара 2.25 с. Пауза 1.45 с + полёт 1.1 с = 2.55 с в круг не влезает.
Сделано: пауза 1.0 с, полёт 1.1 с, прилёт в 18.55 с, запас до шва 0.15 с. Числа — в `heroLoop.js`
(`MARK_HOLD_S`, `MARK_FLIGHT_S`). Альтернативы: пауза 1.45 / полёт ≈0.75 с, либо полёт доходит за шов петли.

## Что лежит
- `sheet-desktop-1920.jpg`, `sheet-phone-390.jpg` — пять кадров: проявился · начало полёта · середина · прилёт · после.
- `<ширина>-1…5-*.jpg` — те же кадры целиком на 1920, 1280, 430, 390, 360.
- `phone-390-4b-vspyshka-pik.jpg` — пик вспышки шапки.
- `*-reduce-motion`, `*-video-failed`, `*-scroll-during-flight` — особые случаи.
- `arc/` — прямая против двух дуг; выбрана вниз-влево (`FLIGHT_ARC = -0.12`).
- `summary.json` — рамки знаков и расхождение на прилёте.

Расхождение центра летящего знака и знака шапки на прилёте: ≤ 0.003 px на 1920, 1280, 430, 390, 360.
