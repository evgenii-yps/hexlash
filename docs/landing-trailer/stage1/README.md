## Что проверено (тестовый браузер Chromium, dev-сервер и боевая сборка `vite build` + `preview`)

1. **Первый экран на 1920×1080, 1280×720, 390×844, 844×390** — `screens/1…5-*.jpg`. Горизонтального
   скролла нет (ширина документа = ширине окна). Ошибок в консоли нет.
2. **Заставка → видео:** разница пикселей между заставкой и первым кадром видео — в среднем 0,3 из 255
   (99 % пикселей ≤ 2): подмена не видна.
3. **«Уменьшить движение»:** видео не создаётся и не запрашивается (в списке запросов только заставка),
   знак виден в покое, слово не бьётся — `screens/6-*.jpg`.
4. **Пауза:** вне экрана видео стоит, при возврате продолжает с того же места; на время открытого
   трейлера фон стоит и потом продолжает.
5. **Знак и удар слова по времени петли:** 12 кругов подряд на скорости ×16 — 0 расхождений на 162
   проверенных кадрах (19 из них в окне удара); после паузы вне экрана состояние кадра верное.
6. **Полёт при прокрутке — до/после:** камера (`--cam-x/y/z`, цвет) и высота страницы сравнены на 9
   позициях прокрутки на трёх размерах (1920×1080, 1280×720, 390×844) между `main` и веткой —
   0 различий. Видео прокрутки рядом: `prokrutka-do-i-posle-1280x720.mp4` (слева `main`, справа ветка).
7. **WATCH TRAILER:** открывается нажатием, звук включён (muted=false, громкость 1, аудио декодируется),
   управление есть; закрывается ×, Esc и нажатием на тёмный фон; нажатие по видео не закрывает;
   после закрытия видео остановлено, фон возобновился, фокус вернулся на кнопку.
8. **Сеть:** до нажатия запросов `trailer-1080.mp4` — 0; после нажатия — 1 на каждое открытие.
9. **Прокрутка под открытым окном** заблокирована (колесо не двигает страницу).
10. **Сборка** `vite build` зелёная.
