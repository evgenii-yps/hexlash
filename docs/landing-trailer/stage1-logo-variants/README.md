# Ролик на лендинге — логотип в конце петли: варианты A и B

Код сайта НЕ менялся. Всё собрано подстановкой видео в страницу «на лету» (тестовый браузер).

Правки владельца, уже внесённые в петлю:
1. Вырезан крупный план дуэли с огромными розовыми кольцами. Дуэль — только общим планом (два куска: трейлер 0:11,9–0:14,85 и 0:17,85–0:20,3, растворение 0,4 с).
2. Вертикальная версия для телефона: бойцы стоят в полосе под кнопками (≈ 78–93 % высоты экрана 390×844), не за кнопками.
3. В конце петли — логотип, затем снова дуэль.

## A — буквально (карточка трейлера в конце петли)
Остров → тьма 0,3 с → карточка логотипа из трейлера с ударом BAM, удержание ≈1,5 с → уход в тьму → дуэль. Длина петли 19,5 с.
Минус виден на снимке «пик»: карточка встаёт ровно под крупное слово HEXLASH сайта — два логотипа друг на друге.

## B — рекомендация (знак над словом сайта + удар слова)
Остров → тьма 1,7 с. В тьме — знак над словом HEXLASH (удар BAM: 150 % → 95 % → 108 % → 100 %), в тот же момент слово сайта делает удар (93 % → 108 % → 100 %), новых свечений нет. Через ≈1,45 с знак гаснет, проявляется дуэль. Длина петли 18,7 с.
Знак — элемент страницы над затемнением, а не часть видео: внутри видео его накрыло бы затемнение 48 % и он стал бы серым рядом с белым словом; к тому же так он всегда точно над словом при любых пропорциях окна. Время удара берётся из времени петли.

Файлы: `loop-A-720p.mp4`, `loop-B-720p.mp4` (петля без знака — знак рисует страница), `loop-B-vertical-720x1560.mp4` (для телефона), кадры `A-*`, `B-*`, `B-phone-*`, записи первого экрана `variant-*-first-screen-clip.mp4` (≈5 с, покадровая съёмка страницы, 15 к/с).
