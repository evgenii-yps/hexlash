ТЗ: «наименьшее значение, при котором оси становятся видны». Замер показал, что это **0**. Видимость даёт уже *выбор ответа внутри нужды*; сама гибкость порога ничего не добавляет:

|---|---|---|---|---|

| 0 | 94.5 / 42.2 / 33.6 | 71.2 / 69.6 / 69.6 | 61.4 / 44.5 / 50.4 | 68.5 / 63.2 / 63.4 |
| 0.1 | 94.5 / 42.2 / 33.6 | 70.9 / 69.4 / 69.3 | 61.4 / 44.6 / 50.5 | 68.4 / 63.1 / 63.3 |
| 0.25 | 94.5 / 42.2 / 33.6 | 70.9 / 69.1 / 68.9 | 61.4 / 44.9 / 50.8 | 68.3 / 63.1 / 63.2 |
| 0.5 | 94.5 / 42.2 / 33.6 | 70.5 / 68.9 / 68.8 | 61.9 / 45.4 / 51.4 | 68.2 / 63.2 / 63.1 |

(шум одной ячейки ≈ 0.3 п.п.; сырьё — `out/sweep-bend-*.json`). Кроме того, **любое bend > 0 сдвигает и голые ядра** (это меняет контрольную сумму боя и метрики с нулевым запасом), а при bend = 0 голые ядра остаются бит в бит. Поэтому ручка оставлена рабочей, но выключена. Включать её или нет — решение для прохода по числам; выше bend ≈ 0.42 тяжёлый боец начнёт бить «на половинном заряде» (граница проверена в `reflex-sight-extremes.mjs`).

Честно про ТЗ: пункт «характер меняет и порог» в выложенном виде **не действует** (bend = 0). Действует вторая половина — «выбор внутри нужды».

## 4. Долг 2 — «клич до выбора намерения не доходит»

Прогон: 200 зёрен × 4 ядра × 3 клича, парные бои на одном зерне (без клича / клич при t ≥ 5 с, как в замере 26.09), сравнение решений игрока в окне 5–13 с (19 200 решений). Сырьё: `out/before-klich.json`, скрипт `reflex-sight-klich.mjs`.

**Утверждение подтвердилось только наполовину, и это меняет запись за 26.09.**

- **Оси не доходят.** Клич двигает четыре оси (distance / initiative / tempo / stick). В `self.ax01`, которое читает выбор намерения, ни одна из них не меняется: **0 из 19 200 решений**. `ax01` собирается из базовых осей сборки (`baseAx` + константы рождения), а клич живёт в отдельной дельте, идущей только в ручки тела (`refreshAxes`). Инициатива, темп и сцепка клича до выбора не доходят вообще.
- **Дальность доходит.** Дистанционная часть клича попадает в `self.range` (= `character.range`, которое собирается как база + клич + намерение): `range` отличается от бескличевого прогона в **19 199 из 19 200 решений** (средний сдвиг 0.08–1.45 ед. по кличам), и выбор `self.range` участвует в двух местах: дальность жёсткого ответа на замах и «близко/далеко» в очках.
- **Итог по выбору намерения:** меняется у **10.7%** решений окна (2 047 из 19 200); сразу на первом решении после броска — у 3.8% (90 из 2 400); по ядрам и кличам — от 0% (ONSLAUGHT — почти вовсе не реагирует, AMBUSH ≤ 4%) до 37% (RAIDER PUSH), BULWARK PUSH 23% / FALL BACK 36%. Часть после первого решения — косвенная (клич сдвинул позицию, позиция сдвинула выбор).
