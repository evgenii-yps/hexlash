## 3. Г2 и Г3

- **Г2 (вес осей в очках мал)** — частично: у ONSLAUGHT на «вразброс» билде очки почти не меняются (5.5%), при целевых ветках 58–66%. Это вопрос чисел, а не шва — не в этой работе.
- **Г3 (решения мимо выбора)** — телесные ветки: атака (`decideAttack`), чтение фазы врага (сбив/контра), блок при входящем ударе, уворот. Частоты на бой (BULWARK): блок-шансов ~20, блоков ~12, контр ~18, сбивов ~2, ударов-серий ~1. По коду все они читают оси косвенно (флаги намерения, `counter01`, `stickEff`, `baseAx.resilience`, `heavy01`), то есть **не слепы по конструкции**; но слепы транзитивно: намерение, которое их питает, на ~47% берётся из `hardNeed`. Отдельного «слепого» пути навигации мимо осей не найдено. Полного контрфакта по траектории не делал (только по решениям).

Как клич/баффы попадают в бой: клич и намерение-дельта питают только `refreshAxes()` (ручки тела: дальность, агрессия, `stickEff`, `effTempo01`), баффы идут через статы; **выбор намерения не видит ни того, ни другого**.
