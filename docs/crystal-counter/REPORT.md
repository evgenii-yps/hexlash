# Счётчик кристаллов: ряд из семи шестиугольников (ТЗ 30.09.2026)

База и точка отката: `d8c14acc` (`origin/main` на момент работы). Ветка `claude/crystal-counter-hexes`.
Слова как в ТЗ: ГРАНЬ = ветка, КРИСТАЛЛ = шаг. В коде наоборот, не переименовывал.

## Что сделано
Текст `LIT n OF 7` снят. Под кнопкой `LIGHT IT`, по центру, отдельной строкой стоит ряд из `RESOURCE` шестиугольников (сейчас 7; число читается из `upgradeData.js`).
- **Зажжённый:** залит цветом ядра бойца, полная непрозрачность. **Пустой:** тонкий контур, без заливки. Заполняются слева направо.
- **Форма:** не новая — обводка «сердца» ядра из `coreFacets` (та же, что у кристалла на ядре, лендинге, деке); рамка вида считается от неё.
- **Тон пустого:** `--ink-dim` (#A9A5AF). Прежний счётчик был `--ink-off` (#5D5D66, «выключено») — слишком тёмный.
- **Все заняты:** `LIGHT IT` остаётся на месте, текст и цвет те же, `disabled` + `opacity: .4` (то же значение, что у `.cab-btn:disabled`), не нажимается. Под рядом строка `NO ROOM — PUT ONE OUT FIRST` тоном `--ink-soft`. Погасил любой — строка исчезает, кнопка возвращается, последний шестиугольник пустеет.
- **Вспышка при зажигании:** кольцо цвета ядра расходится и гаснет, заливка проступает из прозрачности. Яркость не поднимается (красное ядро ушло бы в розовое). Только когда зажжён ровно один кристалл (смена бойца/«Зеркало» не вспыхивают). При «уменьшить движение» остаётся смена прозрачности без расхождения.
- Цвет ряда берётся от ядра бойца и задаётся на самом ряду (в SPAR `--core` у карточки иначе не приходит).
- Для чтения с экрана у ряда подпись `n OF 7 CRYSTALS LIT`; на экране цифр нет.
- Ключ `whySpent` удалён, `litCount` теперь подпись для чтения с экрана, добавлен `noRoom`.

Не тронуты: кнопки `LIGHT IT`/`PUT OUT` (кроме состояния «неактивна»), карточка кристалла выше, фигура бойца, `RESOURCE`, бой, лендинг, дека, вход, прогресс.

Два других ядра (BULWARK, AMBUSH): `pair-*-5-core-*`; ONSLAUGHT — основной ряд. 6. Кадры вспышки: `shots/after-m-6-flash-{natisk,skala}-0..3.png`, **розовых пикселей (≤60 от #FF0069) — 0** на всех восьми (`pairs/pink-count.txt`). 7. То же на 1280×800 — префикс `d`.

Проверено скриптом: при семи — `LIGHT IT` `disabled: true`, строка одна; после гашения строки нет.
