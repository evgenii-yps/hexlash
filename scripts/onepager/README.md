# Одностраничник для инвесторов (PDF)

A4, одна страница, живой текст. Сборка и проверка — по одной команде.

```
node scripts/onepager/build.mjs      # → docs/onepager/HEXLASH_onepager_RU.pdf
node scripts/onepager/verify.mjs     # приёмка (код выхода 1 при любом провале)
```

Нужны `playwright` с Chromium (в песочнице стоят глобально) и, для проверки цветов,
`pip install pymupdf`. Для проверки ещё используются `pdfinfo`, `pdffonts`, `pdftotext` (poppler).

| Что | Где |
|---|---|
| тексты (язык — параметр: `text.ru.json`, `text.en.json` позже) | `text.<lang>.json` |
| выключатели «дека целиком» и «контакт» (по умолчанию выкл.) | `config.json` |
| вёрстка | `template.html`, `style.css` |
| цвета, шрифты, шкала кегля, отступы, разрядка | читаются из `src/styles/tokens.css` (`tokens.mjs`); нет токена — сборка падает |
| ядро «Печать» | `src/data/coreFigure.js` (генератор), статичный кадр, режим quiet = розовое состояние |
| знак | `docs/design-handoff/hexlash_mark/brand/mark-full-512.png`, слово HEXLASH — живой текст |
| шрифты | `fonts/` — только Saira Condensed (700, 900) и JetBrains Mono (400, 700) |

Не влезает на страницу — сборка падает. Режем текст, а не размер: сначала блок 07,
потом вторую строку блока 05, потом мелкие подписи блока 03.

Дата в шапке — день сборки; для воспроизводимости: `ONEPAGER_DATE=03.10.2026`.
Отладка: `ONEPAGER_HTML=/путь/page.html` оставляет собранную страницу; `ONEPAGER_FORCE=1`
собирает PDF даже при переполнении (только чтобы посмотреть, что вылезло).

## Шрифты — откуда

Файлы взяты из реестра npm, не подменены: `@expo-google-fonts/saira-condensed@0.4.1`
(полные TTF, есть ≈ и №; лицензия OFL, текст — `fonts/Saira-OFL.txt`) и
`jetbrains-mono@1.0.6` (woff2, полный набор; OFL/MIT). Подмножества `@fontsource`
для этой страницы не годятся: в них нет ≈, и PDF получил бы третий шрифт.

## Известные границы

- Знак — растр (векторной версии нет): цвета в файле `#FEFEFE` / `#FD0062`, а не канонические
  `#F6F4F6` / `#FF0069` (см. `docs/design-handoff/hexlash_mark/README.md`). Это не цвета PDF
  и проверкой цветов не покрываются. Для печати крупнее A4 нужен вектор.
- Тёмные константы ядра (`#191420 #0d0b11 #120f17 #0b0910`) принадлежат генератору ядра, а не токенам.
