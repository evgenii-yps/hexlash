# hexlash-combat — бой и боец

## 1. Что такое бой в Hexlash

**Игрок — тренер, боец — автономный AI.** Игрок задаёт манеру до боя; в бою боец дерётся сам. Игрок вмешивается точечными рычагами, а не управляет ударами.

Бой 1×1, самоидущий по кнопке FIGHT. Открытая арена: бойцы свободно ходят по плите, заходят с любой стороны, контакт по радиусу в любой точке. Конец — по HP.

⚠️ Прежняя модель «бой у шва» (разлом как граница) **отменена**. Разлом теперь — чистое средовое свечение.

## 2. Три слоя бойца

```
СОЗНАНИЕ   → выбор намерения раз в ~секунду        (intentions.js)
ТЕМПЕРАМЕНТ→ 8 осей поведения, 0–100, нейтраль 50  (behavior.js)
ТЕЛО       → рефлексы: клипы движений и ударов      (buildFighter.js 🔒, intentionMotion.js)
```

### Сознание — 7 намерений

| Намерение | Смысл |
|-----------|-------|
| PRESS | давить |
| STRIKE | рубить |
| STING | жалить |
| HOLD | держать |
| BREAK | разорвать |
| BREATHE | дышать |
| CATCH | ловить |

Выбор изолирован за `chooseIntention(self, foe, memory, fight)` — полный контекст в сигнатуре. Намерение держится между тиками (гистерезис), тело исполняет рефлексом.

**Два мозга, тумблер `brain: spinal | model`:**
- `spinal` — детерминированный «спинной мозг». **Дефолт на проде.**
- `model` — гибрид: на «переломах» боя (старт / HP<30% / стамина<30% / смена манеры врага) будится Claude API (`claude-haiku-4-5`) и выбирает намерение; между переломами работает спинной.

Гибрид: ~5–10 запросов за бой, кулдаун 3с, потолок 12, таймаут 1.5с. Запрос **только через бэк** (`/v1/ai/fighter-intention`) — ключа на фронте нет. В промпт идёт характер **словами** (ядро + зажжённые грани) и память о враге словами, **без сырых осей**.

**Любой сбой / таймаут / 503 / битый JSON → молча откат на спинной мозг.** Бой не фризит. Это не опция, это закон.

⚠️ На проде модель **выключена** (деньги). Включение — отдельное решение владельца.

### Темперамент — 8 осей

`дистанция · инициатива · темп · вес удара · сцепка · стойкость · ответка · скольжение`

0–100, нейтраль 50. Ядро ставит стартовый профиль, грани двигают оси, движок ведёт бойца по профилю. Оси **клампятся** 0–100 — поэтому одна и та же грань на разных ядрах работает по-разному.

Оси наружу (в промпт модели) идут **словами**, не числами.

### Тело — словарь движений

У каждого из 7 намерений своя читаемая манера, поза и скорость — опознаётся за ~0.5с. Tunable в `intentionMotion.js`.

Приёмы: прямые руками · хук · апперкот · по корпусу · три прямых ногой (фронт-кик / тип / колено) · двойка · комбо.

⚠️ Настоящего бокового маха рукой скелет не умеет (плечо/локоть только `rotation.x`). Хук сфабрикован через скрутку корпуса. Настоящая ось отведения плеча = правка скелета, отложена как дорогая (вместе с ударами с разворота).

## 3. Главная связка продукта

**Грань = одна величина в двух проекциях.**

```
зажёг грань → у бойца поднялось ЧИСЛО и сменилась МАНЕРА → проверил на арене
```

Это не «два слоя», а одна величина: **число = характер**. Число идёт телу (арифметика), характер — сознанию (личность для модели). Прокачка = воспитание ИИ.

Карточка грани показывает и число, и манеру. **Карточка не врёт** — оба слоя доходят до боя, материализация на входе в арену.

## 4. Ядра и прокачка

**Четыре ядра (locked, английские имена):** ONSLAUGHT · RAIDER · BULWARK · AMBUSH.
Цвета ядер — `CORE_HUE` в `src/data/sceneTokens.js`.

Drill-down: **ядро → кристалл (ветка) → грань**. «Камера глубины», степпер CORE/CRYSTAL/FACET (он же навигация назад), карточка грани, нижняя полоса BUILD, CTA «TO BATTLE» доступна на всех уровнях.

- Пул `RESOURCE = 5` — зажечь ~5 граней из 60. Создаёт **реальный отказ-выбор**.
- Все грани пока `open`, локов нет. Разная цена граней — будущее.
- Индикатор пула с экрана убран (лимит работает молча).

**Жёсткие ветки** несут % к силе/прочности, рамп по глубине грани ~4/7/10/14/22%. Остальные — поведенческое число.

⚠️ **Теги граней (effects/conditionals, ~33 шт.) мертвы осознанно.** Движок их не читает, карточка не показывает — вранья нет. Оживлять — **не вслепую**: по одной, по тычку владельца.

## 5. Числа и баланс

**Все числа боя — в одном файле: `src/data/combatBalance.js`.** Нигде больше. Это сделано для того, чтобы владелец мог крутить ощущение, не читая код.

Блоки: `kicks` · `hands` · `footwork` · `dodge` · `exhale` · дистанции · урон.

Канон:
- **HP = 100** обоим. (Было 4000 — случайная цифра под старый прицел.)
- Урон = **доля от max HP** цели: `damageFracBase 0.045 × strikePower/100 × moveMult × stamina × jitter`, применяется как `dmg × maxHp`.
  → Рост HP в будущем баланс не ломает, hits-to-kill те же.
- `strikePower` — читаемая характеристика, база 100 (грейд 122 = +22%).
- Триада raw: панч 4.5% · двойка-импакт 6% · комбо 16.5%.
- Длина боя ~15+ чистых попаданий на истощение (~42с). Эскалация-добивание с 25с.
- Дистанции: `STRIKE = 2.0`, атака коммитится с `RANGE = 1.6`, `CONTACT = 0.74`, `FAR = 1.9`.
- Дальность удара — данные (`strikeReach`): джеб короче, кик дальше, колено вплотную.

**Правило правки баланса:** менять числа в `combatBalance.js`, проверять в лаборатории и на арене глазами, не трогать логику выбора намерений.

## 6. Ритм и моторика

- Перемещение: настоящий переступ, плавный разгон/торможение и поворот, непрерывное кружение вокруг врага. Не замирают, не стоят параллельно.
- Бой **дышит по дистанции**: чередуются фазы сближения-размена и разрыва с маневром.
- Ритм «дуга движения → короткий устой» (0.7–1.6с). Во время устоя возвращается силуэт стойки по намерению: HOLD врос, CATCH сжался, BREATHE сник.
- **Выдох после удара**: короткое оседание плеч и таза, плавный blend обратно в движение. Комбо оседает глубже и дольше джеба. Удар не щёлкает в стойку.
- Урон = **вздрог с отдачей**: резкое весомое отшатывание + мигание ядра (ярче → провал), затем плавный возврат в стойку.
- Выбывание = **растворение во тьму**: тело темнеет в фон и тает в тумане (не падает), ядро держится и гаснет последним.
- Уклон — плавный боковой шаг настоящим переступом; боец после уклона остаётся off-line, а не возвращается в точку. ⚠️ Пробное решение: если бойцы «расползаются» по арене, вернуть прежний возврат.

Характер моторики: **плавно и тяжело** — медленный замах, резкий момент удара, весомый возврат. Не резко-роботно.

## 7. Лаборатория бойца

Дев-онли роут `/dev/lab`, не в меню. Дом для доводки всей моторики.

- Боец на подиуме, орбита камерой + снапы (спереди / три четверти / сбоку).
- Запуск любого из 7 намерений и любого приёма с панели.
- Транспорт: один раз / цикл / пауза / замедление / покадрово.
- Полоса времени приёма с фазами замах / контакт / возврат + бегунок-прокрутка (тянется мышью на паузе).
- Счётчик «кадр N / M», авто-пауза на кадре контакта (тумблер, дефолт OFF).
- Затухающий след за бьющей конечностью (дефолт ON для ударов).
- Сводка манеры для намерения: направление / дистанция / темп / наступ / удар / защита.
- Дев-замок LOCK — проверить движение в изоляции.

Играет **через тот же `buildFighter.update`, что и бой** (виртуальные часы). Отдельной системы анимаций нет — то, что видно в лаборатории, и есть то, что будет в бою.

Новое движение добавляется одной строкой-дескриптором.

## 9. Что НЕ построено

Не предлагать как «просто доделать» — это большие отдельные заходы:

- Клич тренера (переделка с нуля)
- Баффы-жетоны — второй тип in-fight рычага
- Слой «после боя» — разбор и последствия
- Команды на арене (несколько бойцов на сторону)
- Система карт граней (грани → кристаллы с анлоком/покупкой)
- Прокачка HP (1000+)
- Удары с разворота, настоящая ось отведения плеча
