| VOID | `#08080A` | Фон приложения, внутренний зазор focus-ring | никогда |
| PANEL | `#16161B` | Поднятые поверхности, карточки, двери | никогда |

| ASH | `#6E6A72` | Тусклые mono-сублейблы | никогда |

## 2. Линии и поверхности

```css
--line:  rgba(255, 255, 255, 0.09);   /* обычная волосяная линия */
--line2: rgba(255, 255, 255, 0.16);   /* волосяная-сильная: рамка матового хрома */
--card:  rgba(255, 255, 255, 0.022);  /* едва заметная заливка карточки */
```

⚠️ В `shop.css` `--line2` = `rgba(255,255,255,0.05)` — локальное переопределение под магазин. Не «чинить», это осознанно.

## 3. Бренд

```css
--hex-primary: #FF0069;               /* HEXLASH PINK — единственный розовый */
--acc-rgb:     255, 0, 105;           /* для rgba()-подмесов */
--hex-primary-dark:  #A50344;
--hex-primary-glow:  rgba(255, 0, 105, 0.5);
```

Владеет: главный CTA (FIGHT), BUY, баланс, активная вкладка, BEST VALUE / HOT DEAL, маяк лидера в сцене пространства, дуга подсказки поворота экрана.

Снят из проекта: `#FF066F` (легаси-розовый). В живом коде быть не должно.

## 5. Материалы тренера (low-poly декор, матовые)

```
SAND   #C9B8A0
RUST   #E86134
TEAL   #2F86A8
CHROME #C8D1D8 → #585F68
AMBER  #FFB21D   /* тёплый ламповый / контактный свет; акцент PVE */
```

Эти краски живут **в 3D на телах декора**. В UI не лезут. Исключение — AMBER как акцент режима PVE.

## 6. Семья «матовый хром» — вторичные контролы

Класс `.hs-chrome` в `src/styles/home.css`. Члены: SHOP · cabinet · EDIT SPACE · back. Шарится домом, магазином и PVE.

```css
--hs-chrome-ink:        #C8D1D8;                    /* глиф + подпись в покое */
--hs-chrome-ink-dim:    #5D5D66;                    /* disabled */
--hs-chrome-line:       rgba(200, 209, 216, 0.16);  /* рамка в покое */
--hs-chrome-rim:        rgba(216, 227, 234, 0.45);  /* ободок hover */
--hs-chrome-rim-hot:    rgba(216, 227, 234, 0.80);  /* ободок active */
--hs-chrome-bloom:      rgba(200, 209, 216, 0.22);  /* блум hover */
--hs-chrome-bloom-hot:  rgba(200, 209, 216, 0.30);  /* блум active */
--hs-chrome-glass:      rgba(22, 22, 27, 0.55);     /* стекло в покое (+ blur 8px) */
--hs-chrome-glass-hover:rgba(28, 30, 37, 0.72);     /* заливка hover */
--hs-chrome-void:       #08080A;                    /* внутренний зазор focus-ring */
```

**Форма:** чистый прямоугольник, `border-radius: 0`. Без HUD-уголков, без диагонального среза (ретирированы 30.06.2026).

**Свечение только хром-холодное, никогда розовое.**

## 7. Геометрия и формы

```css
--hs-hex:      polygon(24px 0, calc(100% - 24px) 0, 100% 50%,
                       calc(100% - 24px) 100%, 24px 100%, 0 50%);
--hs-bevel:    9px;
--hs-chamfer:  polygon(0 0, 100% 0, 100% calc(100% - var(--hs-bevel)),
                       calc(100% - var(--hs-bevel)) 100%, 0 100%);
--padx:        76px;   /* горизонтальный паддинг лица FIGHT — очищает острия гекса */
```

- `--hs-hex` — гекс-плита FIGHT.
- `--hs-chamfer` — срез угла «fight-card»: двери экрана режимов, модальные листы.

## 8. Движение

```css
--hs-spring:    cubic-bezier(0.22, 0.61, 0.36, 1);  /* пружина */
--ease-settle:  cubic-bezier(0.20, 0.80, 0.20, 1);  /* прилёты, мягко, без перелёта */
--ease-weight:  cubic-bezier(0.55, 0.00, 0.12, 1);  /* тяжёлый хром / плиты */

--hs-fast:  0.15s;   /* смена цвета/рамки */
--hs-hover: 0.22s;   /* подъём + ободок/свечение */
--hs-press: 0.12s;   /* просадка на нажатии */
```

Подробности по анимации — скил `hexlash-motion`.

## 9. Шрифты

```css
--hs-disp: "Saira Condensed", "Arial Narrow", "Roboto Condensed", system-ui, sans-serif;
--hs-mono: "JetBrains Mono", ui-monospace, monospace;
```

В `shop.css` те же под именами `--disp` / `--mono`.

Подключение — неблокирующее, в `index.html`. Экран загрузки рисуется **до** стилей приложения, поэтому в нём цвета литералами и системные фолбэки.

## 10. Легаси-слои — НЕ использовать

**`src/styles/hexlash-ui.css`** — `:root` выпотрошен с 135 до ~21 работающего токена (30.06.2026). Осталось только то, что реально кем-то читается. Ничего сюда не добавлять.

**`src/styles/v24/tokens.css`** — старый слой под `.app-v2`. ⚠️ **Легаси, но ЖИВОЙ:** грузится на всех `/play/*` по цепочке `AppV2.vue` → `hexlash-v24.css` → `v24/tokens.css`.

- Импортирует с Google Fonts **Archivo Black + Space Grotesk** (канон — Saira Condensed + JetBrains Mono).
- Ставит `font-family: var(--font-body)` **на сам `.app-v2`** → Space Grotesk сейчас базовый наследуемый шрифт игрового шелла. Всё, что не задало шрифт явно, рендерится им.
- `--bg-deep: #070811`, `--bg-panel: rgba(14,16,28,.85)` — старые фоны.
- Токены `--font-display` / `--font-body` за пределами этого файла **не используются никем**.

Живые потребители класса `.app-v2`: `AppV2.vue`, `ArenaScene.vue`, `FighterLabScene.vue`, `router/index.js`, `assets/main.css`, `v24/effects.css`, `v24/verify.css`. Поэтому слой нельзя просто удалить.

**Правило:** новое **всегда** задаёт шрифт явно (`--hs-disp` / `--hs-mono`, в магазине `--disp` / `--mono`), не полагаясь на наследование. Слой не расширять. Приведение к канону — отдельная задача с проверкой всех `/play/*`.

⚠️ **Ловушка:** `--hex-primary` = `#FF0069` определён внутри `.app-v2`. Компонент, вынесенный из `.app-v2` через `<Teleport>`, потеряет правильный розовый. Кабинет игрока именно поэтому НЕ телепортируется.
