# Существующие компоненты — спеки

Прежде чем делать новый компонент, проверь: скорее всего, он уже здесь.
Обзор поведения — в `../SKILL.md`.

## FIGHT — якорь дома

**Где:** `HomeView.vue` + `home.css`.

- Объёмная hex-плита из трёх слоёв: розовый bloom → тёмный цоколь (толщина) → подсвеченная грань.
- Форма `--hs-hex`, горизонтальный паддинг `--padx: 76px` (очищает острия).
- Sheen + весомые idle/hover/press. Idle-пульс ~3.4s.
- Появляется последним в стаггере входа.
- Единственный розовый и единственное свечение в покое на доме.
- Ведёт на `/play/mode` (Mode Select), **не** прямо на арену.

⚠️ Отдельная приёмленная спека. Не трогать попутно.

## `.hs-chrome` — семья матового хрома

**Где:** `home.css`. Члены: SHOP · cabinet · EDIT SPACE · back. Шарится домом, магазином, PVE.

| Свойство | Значение |
|----------|----------|
| Форма | прямоугольник, `border-radius: 0` |
| Высота | 44 / 48 / 44×44 (иконка) |
| Подпись | Saira Condensed 700, 14px, `letter-spacing .14em`, UPPERCASE |
| Глиф | слева, 17px, gap 10px, `#C8D1D8` → `#fff` на касании |
| rest | рамка `1px rgba(200,209,216,.16)`, стекло `rgba(22,22,27,.55)` + `blur(8px)` |
| hover | ободок `0 0 0 1px rgba(216,227,234,.45)` + блум `0 0 18px 2px rgba(200,209,216,.22)`, заливка `rgba(28,30,37,.72)`, `translateY(-1px)`, sheen один раз |
| active | ободок `.8` + блум `0 0 14px 1px rgba(200,209,216,.3)`, `scale(.985)` |
| focus-visible | `0 0 0 2px #08080A, 0 0 0 4px rgba(216,227,234,.7)` — **без блума** |
| disabled | рамка `--line`, заливка `rgba(22,22,27,.4)`, чернила `#5D5D66` |
| Движение | easing `cubic-bezier(.55,0,.12,1)`; hover `.22s` / press `.12s` / sheen `.6s` |
| reduced-motion | только цвет и тень; без трансформов и sheen |

**Жёстко:** розового нет · свечения в покое нет · пульса в покое нет. Не пересвечивать FIGHT.

## `.hs-strip` — верхняя панель

**Где:** `home.css`. ⚠️ Шарится домом + магазином + PVE.

- Высота 48px, обе стороны на одной оси.
- Слева: бренд-знак (`HexlashMark`, бокс 40px — упрощённая отрисовка, порог 48) + слово `HEXLASH`, единым прозрачным кликом → дом.
- Справа: кластер SHOP + чип кабинета, оба на `.hs-chrome`.
- Матовая. Свечения нет.
- В магазине SHOP → `← BACK`.
- На PVE бренда нет, слева `← BACK` внутри полосы как левый flex-child.
- На Mode Select полосы нет вовсе.
- Чип кабинета — хром-ромб 28×28, нейтральный, без ника.
- Баланса нет (Этап 2).

⚠️ `.hs-bal` (баланс) шарится домом и шопом — класс не удалять, даже если на доме не рендерится.

## Магазин — классы `sb-*`

**Где:** `src/styles/shop.css` + `HomeShop.vue`. Mobile-first + `@media (min-width: 880px)`.

Структура: шапка (баланс · заголовок SHOP · переключатель вкладок с розовым андерлайном) → кредо «Cosmetic Only · No Pay-to-Win» → лид вкладки → лента.

Три вкладки: **Decor · Currency · Specials** (вкладочный, не простыня).

- **DECOR** — 6 presence-карточек. Привязка к ядру: banner→ONSLAUGHT (hero), plinth→AMBUSH, dais→BULWARK, crates→RAIDER, arch→ONSLAUGHT. Featured-карточка несёт **единственное свечение экрана** (bloom, 2×2 на десктопе). Теги NEW / OWNED / FEATURED.
- **CURRENCY** — инфо-панель «What is $HEX», лесенка ценности, hex-pile чипы, розовое кольцо BEST VALUE (только когда стадия live).
- **SPECIALS** — таймер hot-deal, free-claim, bundle. Акцент ядра AMBUSH только на рамке.

Модалки buy / wallet / claim — листы с HUD-уголками (уголки экрана `.sb-bk` сняты, уголки модалок `.sh-bk` оставлены).

Флаг `stageTwoLive = false` → Currency/Specials показывают честные SOON без колец.
BUY — заглушка: confirm → Unlocked, баланс не списывается, владение не сохраняется.

Скролл — цельный (см. `../SKILL.md`, §10).
Эталон: `docs/design-handoff/_archive/shop_bright/`.

## Экран загрузки «Fight Card»

**Где:** `index.html` (инлайном), правится вручную.

- Крупный процент-герой 0–100 с ведущим нулём.
- Кредо `NEVER GIVE UP` → на 100% переключается в `STEP IN.`
- Тонкая полоса прогресса, ротация «полевых заметок» (FIELD NOTE → ARENA READY).
- Верхний лок-ап «знак + HEXLASH», HUD-уголки.
- Фон — сплошной + один радиальный ember-градиент.

⚠️ Живёт **до** стилей и шрифтов приложения: токены `--hex-*` и веб-шрифты недоступны. Цвета — литералами (`#FF0069`), шрифты — системные фолбэки.

Прогресс честный: по вехам бутстрапа (бандл → mount → сборка сцены → первый кадр).

## `RotateHint` — подсказка «поверни телефон»

**Где:** `src/views-v2/RotateHint.vue`, смонтирован один раз в `AppV2.vue` (живёт только в `/play/*`).

- Матовый хром-контур телефона (семья `.edit-space`), крутится вертикаль ↔ −90°, период 1.8с.
- Единственный розовый/bloom — дуга-стрелка `#FF0069` вокруг.
- Показ: `coarse && portrait && sceneTransition.mode==='none' && !dismissed`.
- Тап закрывает. Поворот убирает и сбрасывает флаг. Флаг только в памяти.
- `prefers-reduced-motion` → статика без вращения.
- Строки — блок `rotateHint` в `en.js`.
