# Дисциплина свечения — подробно

Свечение в Hexlash — не украшение, а **система приоритетов**. Светится то, куда нужно смотреть. Если светится всё — не светится ничто.

---

## 1. Бюджет свечения на экран

Считай перед сдачей экрана:

| Слот | Сколько | Кто занимает |
|------|---------|--------------|
| Геройский bloom | **ровно 1** | Главный CTA экрана или одна featured-карточка |
| Ценностное кольцо | **0 или 1** | BEST VALUE / HOT DEAL |
| Реактивное свечение | сколько угодно, но **только на касании** | Ховер/нажатие вторичных контролов |
| Средовое свечение (3D) | **1** | Ядро бойца, разлом, маяк лидера, лампы |

**Больше одного bloom в покое = ошибка.** Не «немного перебор» — ошибка, которую нужно исправить до сдачи.

## 2. Иерархия — от сильного к слабому

```
1. Геройский bloom       ← самое яркое, единственное
2. Кольцо BEST VALUE/HOT ← тоньше, только когда стадия live
3. Кнопка BUY            ← ещё тише
4. Ховер-ободок          ← только пока палец/курсор на элементе
```

Ни один нижний уровень не должен визуально перебивать верхний.

## 3. Два вида свечения — не путать

**Розовое (`#FF0069`)** — якорь и экономика.
Где: главный CTA (FIGHT), BUY, баланс, активная вкладка, ценностные кольца, маяк лидера.
Где нельзя: вторичные кнопки, хром-панель, логотип, тело товара.

**Хром-холодное (`rgb(216,227,234)` ободок / `rgb(200,209,216)` блум)** — вторичные контролы.
Где: SHOP, cabinet, EDIT SPACE, back — **только на hover/active**, никогда в покое.
Смысл: панель шарится с домом, где FIGHT — якорь. Если вторичные засветятся, они начнут спорить с якорем.

**Цвет ядра** — товар и личность бойца.
Где: свечение карточки товара, контактный ободок, глиф за вещью, ядро бойца в 3D, ореол в кабинете.
Никогда вместе с розовым в одном элементе.

## 4. Свечение как СВЕТ, а не заливка

Ключевое правило витрины: **предмет остаётся арена-серым**. Принадлежность к ядру читается:

- bloom вокруг предмета,
- контактным ободком по краю карточки,
- цветным глифом-eyebrow над названием,
- одной цветной мотой (пятном света) ЗА матовой вещью.

❌ Перекрасить сам предмет в цвет ядра. Пробовали в июне — вышла «разноцветная вакханалия», откатили.

## 5. Где свечение запрещено — полный список

| Место | Почему |
|-------|--------|
| Верхняя хром-панель (`.hs-strip`) | Матовая, шарится домом/магазином/PVE — она рама, а не содержание |
| Вторичные кнопки в покое | Не должны спорить с якорем FIGHT |
| SOON / гейтнутое | Светится то, что можно нажать |
| OWNED / купленное | Уже твоё — нечего продавать |
| Основной текст | Читаемость важнее эффекта |
| Матовые тела декор-артов | Материал тренера — матовый по определению |
| Логотип и favicon | Отдельное правило бренда: монохром, без свечения |
| disabled-состояние | Чернила `#5D5D66`, ни ободка, ни блума |
| focus-visible | Кольцо фокуса — **без** блума (иначе не отличить от hover) |

## 6. Рецепты — как выглядит правильно

**Геройский bloom карточки:**
```css
.card--featured {
  box-shadow:
    0 0 0 1px rgba(var(--core-rgb), .35),      /* контактный ободок */
    0 0 48px 6px rgba(var(--core-rgb), .18);   /* мягкий bloom */
}
```
Мягкий и широкий. Не резкий ореол.

**Ховер вторичной кнопки (хром):**
```css
.hs-chrome:hover {
  box-shadow:
    0 0 0 1px var(--hs-chrome-rim),      /* rgba(216,227,234,.45) */
    0 0 18px 2px var(--hs-chrome-bloom); /* rgba(200,209,216,.22) */
  background: var(--hs-chrome-glass-hover);
  transform: translateY(-1px);
}
```

**Нажатие:**
```css
.hs-chrome:active {
  box-shadow:
    0 0 0 1px var(--hs-chrome-rim-hot),      /* .80 */
    0 0 14px 1px var(--hs-chrome-bloom-hot); /* .30 */
  transform: scale(.985);
}
```

**Фокус с клавиатуры — без блума:**
```css
.hs-chrome:focus-visible {
  box-shadow:
    0 0 0 2px #08080A,                    /* внутренний зазор на фоне */
    0 0 0 4px rgba(216, 227, 234, .70);   /* само кольцо */
}
```

**Disabled:**
```css
.hs-chrome:disabled {
  border-color: var(--line);
  background: rgba(22, 22, 27, .40);
  color: #5D5D66;
  box-shadow: none;
}
```

## 7. Свечение в 3D-сценах

3D живёт по тем же правилам, но «экран» — это сцена.

| Сцена | Единственное свечение |
|-------|----------------------|
| Дом | Ядро бойца (+ FIGHT в 2D-слое поверх) |
| Арена | Ядро игрока (ярче) → ядро противника (приглушено) → разлом как средовой ambient |
| PVE | Янтарное ядро легенды `#FFB21D` — тёплый якорь. Розового на экране нет. |
| Пространство | Розовый маяк лидера. Остальные 14 бойцов приглушены. |

Тёплая заливка ламп (`AMBER`) — это **освещение**, а не акцент; она не считается свечением и не конкурирует с ядром. Ядро рисуется additive и постоянно — свет ламп его не перекрашивает.

⚠️ Аддитивные гало-спрайты вокруг ламп были убраны с PVE — висели пятнами в воздухе. Лампа должна читаться «горит изнутри», а не «вокруг неё туман».

## 8. Быстрая проверка перед сдачей экрана

1. Сделай скриншот экрана **в покое** (без ховера).
2. Прищурься / расфокусируй взгляд.
3. Сколько ярких пятен видно?
   - **1** → хорошо.
   - **2** → допустимо, если второе — ценностное кольцо.
   - **3+** → переделывать.
4. Самое яркое пятно — это то, куда игрок должен нажать? Если нет — иерархия сломана.
5. Есть ли розовый на вторичной кнопке или логотипе? Если да — баг.
