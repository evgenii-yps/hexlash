# hexlash-design — визуальный язык

## Главное правило в одну строку

**Тёмный фон. Один розовый. Одно геройское свечение на экран. Цвет всегда что-то значит.**

## 1. Где живёт правда о цвете

Источник правды по возрастанию доверия: этот скил → `docs/design-handoff/*` (эталон конкретного экрана) → живой CSS в `src/styles/`.

⚠️ **Важно про токены.** В репозитории лежат ТРИ слоя переменных, и они не равны:

| Файл | Статус | Что делать |
|------|--------|-----------|
| `src/styles/home.css`, `shop.css`, `cabinet.css` | ✅ **актуальные** | Здесь живёт нынешний язык. Работай тут. |
| `src/styles/hexlash-ui.css` | ⚠️ легаси-слой | `:root` ужат до ~21 работающего токена. Не расширять. Не добавлять сюда новое. |
| `src/styles/v24/tokens.css` | ⚠️ легаси-слой, но **ЖИВОЙ** | Грузится на всех `/play/*` через `AppV2.vue` → `hexlash-v24.css`. Содержит **устаревшие шрифты** Archivo Black / Space Grotesk и ставит `font-family: var(--font-body)` прямо на `.app-v2` — то есть Space Grotesk сейчас является базовым наследуемым шрифтом игрового шелла. Канон другой (§3). Новое сюда не добавлять; про открытый техдолг — §3. |

**Перед добавлением любого нового цвета или токена — стоп.** Новый цвет заводится только осознанным именованным набором и только после решения владельца.

## 3. Типографика — канон закрыт

Ровно два шрифта. Оба подключены **неблокирующе** в `index.html`.

| Голос | Шрифт | Где |
|-------|-------|-----|
| Ударный / дисплейный | **Saira Condensed** (500–900) | Заголовки, подписи кнопок, крупные цифры, бренд-слово |
| Телеметрия / мета | **JetBrains Mono** (400–700) | Мелкие подписи, счётчики, служебные метки, eyebrow |

Фолбэки обязательны: `"Saira Condensed", "Arial Narrow", "Roboto Condensed", system-ui, sans-serif` и `"JetBrains Mono", ui-monospace, monospace`.

⚠️ **Anonymous (pixel) удалён из проекта полностью.** Если встретил в коде — это легаси-хвост.

### ⚠️ Открытый техдолг: канон шрифтов НЕ доведён до конца

Канон закрыт 30.06.2026, но `src/styles/v24/tokens.css` живёт до сих пор и **грузится на всех `/play/*`**:

```
AppV2.vue → hexlash-v24.css → v24/tokens.css
```

Что он делает:
1. Тянет с Google Fonts **Archivo Black + Space Grotesk** — лишний сетевой запрос на каждом игровом экране.
2. Ставит `font-family: var(--font-body)` **на сам `.app-v2`** → Space Grotesk становится базовым наследуемым шрифтом игрового шелла. Всё, что не задало шрифт явно, рендерится им.

Спроектированные экраны (дом, магазин, кабинет, двери) шрифт задают сами и выглядят правильно. Наследование ловит только текст без явного шрифта.

**Как с этим работать сейчас:**
- Новое **всегда** задаёт шрифт явно: `--hs-disp` / `--hs-mono` (или `--disp` / `--mono` в магазине). Не полагаться на наследование.
- Токены `--font-display` / `--font-body` **не использовать** — у них сейчас ноль потребителей, кроме самого `.app-v2`.
- Слой не расширять.

**Чинить — отдельной задачей, не попутно.** Это не «удалить мёртвый файл»: у `.app-v2` есть живые потребители (`ArenaScene`, `FighterLabScene`, `GroundSelectView`, роутер, `main.css`). Правка требует перевести слой на канон, не сломав `/play/*`, и проверить на всех игровых экранах.

Правила набора:
- Подписи кнопок — Saira Condensed 700, UPPERCASE, `letter-spacing: .14em`.
- Основной текст — `#EDEDF1`, не `#FFFFFF`.
- ALL CAPS только для лейблов и ударных слов (≤3 слов).
- Максимум 3 размера шрифта на экран.
- Цифры, которые меняются, — `font-variant-numeric: tabular-nums` (не прыгают).

## 4. Дисциплина свечения — сердце системы

Это то, что отличает Hexlash от «разноцветной неоновой вакханалии». Подробности и примеры: `references/glow.md`.

**Иерархия свечения (сильнее → слабее):**

1. Геройский bloom (одна featured-карточка / главный CTA)
2. Кольцо BEST VALUE / HOT DEAL
3. Кнопка BUY
4. Ховер-ободок

**В покое на экране максимум: один bloom + одно кольцо.** Всё остальное молчит и оживает только на касании.

**Свечение ЗАПРЕЩЕНО:**
- на верхней хром-панели (матовая, шарится домом/магазином/PVE);
- на SOON и гейтнутых элементах;
- на купленном (OWNED);
- на основном тексте;
- на матовых телах декор-артов;
- на логотипе (см. §6).

**Свечение вторичных кнопок — хром-холодное, НИКОГДА не розовое.** Ободок `rgb(216,227,234)`, блум `rgb(200,209,216)`. Розовый = только якорь (FIGHT) и экономика.

## 5. Правило «цвет = сигнал»

Шесть правил яркого направления (приняты 26.06.2026, канон):

1. **Одно геройское свечение на экран.** Ровно одна карточка светится в покое; остальные сдержаны до ховера.
2. **Один акцент на элемент.** Карточка носит ОДИН цвет: своё ядро ИЛИ розовый. Никогда два ядра в одном элементе. Никогда розовый + ядро в одном элементе.
3. **Цвет — сигнал, не декор.** Цвет ядра всегда значит «привязано к этому ядру». Нет цвета без смысла.
4. **Розовый владеет хромом и экономикой, ядра владеют товаром.** Не смешиваются.
5. **Иерархия свечения** соблюдается (см. §4).
6. **Где свечение запрещено** — см. §4.

**«Цвет = ядро» — это СВЕТ, не заливка.** Предмет остаётся арена-серым (матовый материал), ядро читается свечением / контактным ободком / глифом ЗА вещью. **Перекрашивать сам предмет в цвет ядра — ошибка** (пробовали, откатили).

## 6. Логотип — исключение из всех правил

Логотип Hexlash **не подчиняется дизайн-системе**. Он монохромный: без розового, без свечения, всегда. Это осознанное разделение бренда и UI.

- Знак — `.hxl-mark` / компонент `LogoMark`, бокс 40px в панели.
- Favicon и PWA-иконки — тот же знак, тёмная плитка `#08080A` + знак `#F6F4F6`. Растеризатор воспроизводим: `scripts/gen-favicons.mjs`.
- Заголовок вкладки на всех маршрутах — `hexlash.com`.

## 7. Направление: система идёт ЯРЧЕ (с 26.06.2026)

Развилка «яркая косметика vs строгая дисциплина» закрыта **в сторону яркой**. Вся система поэтапно ярче.

- **Авангард — магазин.** Он уже в ярком языке.
- Остальное (дом, PVE, арена, mode/ground select) пока матовое и догонит позже.
- Палитра расширяется **только осознанным именованным набором**, не свободным неоном.
- «Один розовый / одно свечение» **ослабляется** для яркого направления — но заменяется правилами из §5, а не отменяется.

**Neon Discipline как глобальный слой выведена** (30.06.2026). Не ссылайся на неё как на действующий свод — новое строим на языке лендинга/входа + брендбуке.

**Неизменно при любом направлении:** косметика-онли. `$HEX` не влияет на бой. Движок желания — самовыражение, статус, редкость. Не сила.

## 8. Ядра как визуальные личности

Четыре ядра — не просто палитра, это **и боевая личность, и витринная категория**.

| Ядро | Характер | Цвет |
|------|----------|------|
| ONSLAUGHT | Напор | `#FF3344` |
| RAIDER | Скорость / жадность | `#FFA526` |
| BULWARK | Стойкость | `#2ED6B0` |
| AMBUSH | Засада / хитрость | `#9461FF` |

Имена всегда английские, всегда UPPERCASE. Палитра ядер — **наша**; альтернативные наборы (cyan/green/purple) отклонены дважды, не предлагать заново.

В 3D: у бойца **одно светящееся ядро**. Свой/чужой различается яркостью ядра + чуть более тёмным и холодным корпусом у противника. **Без второго акцентного цвета.**

## 9. Материал бойца (для 3D-задач)

- Огранённый low-poly, чёткие плоскости (как плита арены). Без гладких реалистичных поверхностей.
- Единая тёмная сине-серая «шкура», тот же материал, что у плит арены — «из одного цеха».
- Одно светящееся ядро в цвете своего ядра, просвечивает сквозь огранку.
- Форма бойца может быть любой (робот, зверь, человек, энергосущность) — семью держит **общий материал, не форма**.

## 10. Антипаттерны — так не делаем

| ❌ Нельзя | ✅ Вместо этого |
|-----------|----------------|
| Второй розовый оттенок | Один `#FF0069` |
| Два свечения в покое на экране | Одно геройское + максимум одно кольцо |
| Розовый на вторичной кнопке | Хром-холодное свечение только на касании |
| Розовый + цвет ядра в одном элементе | Один акцент на элемент |
| Перекрасить товар в цвет ядра | Свет, ободок, глиф за вещью |
| Чисто-белый `#FFFFFF` в тексте | `#EDEDF1` |
| Новый цвет «для красоты» | Стоп → к владельцу |
| Свечение на логотипе | Логотип всегда матовый монохром |
| Свечение на SOON / OWNED / disabled | Матово, `#5D5D66` |
| Anonymous / Impact / Archivo Black | Saira Condensed + JetBrains Mono |
| Токены в `hexlash-ui.css` или `v24/tokens.css` | Актуальные слои: `home.css` / `shop.css` / `cabinet.css` |
