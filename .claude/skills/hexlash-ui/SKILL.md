# hexlash-ui — как интерфейс себя ведёт

Этот скил про **поведение**, а не про цвет. Цвет — в `hexlash-design`. Анимация — в `hexlash-motion`.

Полные спеки существующих компонентов: `references/components.md`.

## 1. Закон состояний

**У каждого интерактивного элемента ровно шесть состояний. Ни одно не пропускается.**

| Состояние | Что происходит |
|-----------|----------------|
| **rest** (покой) | Матово. Ничего не светится, ничего не пульсирует — кроме одного якоря экрана |
| **hover** | Ободок + мягкий блум + подъём `translateY(-1px)`. Только на устройствах с курсором |
| **active** (нажато) | Ободок ярче + просадка `scale(.985)`. Отклик мгновенный |
| **focus-visible** | Кольцо фокуса **без** блума. Обязательно — по нему ходят с клавиатуры |
| **disabled** | Рамка `--line`, чернила `#5D5D66`, ни ободка, ни блума, `cursor: default` |
| **loading / pending** | Элемент не пропадает и не «прыгает»: подпись меняется, размер держится |

Пропущенный `focus-visible` — самая частая ошибка. Он не равен `:focus`: `:focus` ловит и мышь, `focus-visible` — только клавиатуру.

⚠️ Никогда не убивай контур фокуса через `outline: none` без замены. Замена обязательна.

## 2. Иерархия кнопок

В Hexlash три семьи кнопок. Смешивать нельзя.

### Якорь — FIGHT

Единственный на экран. Единственный розовый. Единственное свечение в покое.

- Объёмная hex-плита из трёх слоёв: розовый bloom → тёмный цоколь (толщина) → подсвеченная грань.
- Форма — `--hs-hex`.
- Idle-пульс ~3.4s. Он и есть «жизнь» экрана.
- Появляется **последним** в стаггере входа.
- **Не трогать без отдельного задания.** У FIGHT своя спека, он приёмлен глазами.

### Вторичные — семья «матовый хром» (`.hs-chrome`)

Члены: **SHOP · cabinet · EDIT SPACE · back**.

- Форма: чистый прямоугольник, `border-radius: 0`. Без HUD-уголков, без диагонального среза.
- В покое матово и тихо. Ни розового, ни свечения, ни пульса.
- На касании — короткое **хром-холодное** свечение + один проход sheen.
- Высота: **44** / 48 / 44×44 (только иконка).
- Подпись: Saira Condensed 700, 14px, `letter-spacing .14em`, UPPERCASE.
- Глиф слева 17px, gap 10px, цвет `#C8D1D8` → `#fff` на касании.

Точные значения теней — `../hexlash-design/references/glow.md`, §6.

### Двери — крупный выбор («fight-card»)

Экран режимов — острова ARENA / FORGE.

- Поверхность PANEL `#16161B` + срез угла `--hs-chamfer`.
- В покое спокойны. Свечение — на ховере и в состоянии `armed`, **максимум один bloom на дверь**.
- У каждой двери свой единственный акцент: PVE — янтарь `#FFB21D`, PVP / ARENA — розовый `#FF0069`.
- Дверь, ведущая в незаконченный режим, **не помечается SOON снаружи**, если внутри есть честный превью: метка живёт внутри сцены (см. §7).

## 3. Тач и размеры

Игра играется **с телефона**. Проектируем пальцем, не курсором.

- Минимальная тач-зона — **44×44 px**. Визуально элемент может быть меньше, зона нажатия — нет.
- Между соседними тач-целями — минимум 8px просвета.
- Hover-состояний на телефоне нет: всё, что важно, должно читаться **в покое**. Hover — только украшение.
- Никаких взаимодействий, которые требуют точности мыши (мелкие крестики, тонкие ползунки без запаса).
- Проверяй на `pointer: coarse`, а не только на ширине экрана.

```css
@media (pointer: coarse) { /* телефон/планшет */ }
@media (pointer: fine)   { /* мышь */ }
```

## 4. Ориентация экрана

Игра **рекомендует** горизонтальную ориентацию, но **не заставляет**.

Оверлей `RotateHint.vue`, смонтирован один раз в `AppV2.vue` — живёт только в игровом шелле `/play/*`, на лендинге и auth его нет.

Логика показа:
```
coarse && portrait && sceneTransition.mode === 'none' && !dismissed
```
- На десктопе (`pointer: fine`) оверлея нет вовсе.
- Появляется только **после** завершения загрузки/перехода — не поверх экрана загрузки.
- Тап закрывает: играть в вертикали можно.
- Поворот в горизонталь убирает его сам и сбрасывает `dismissed` → подсказка вернётся при следующем возврате в вертикаль. Это **не** разовый туториал; флаг живёт в памяти, не в localStorage.

## 5. Верхняя панель

`.hs-strip` в `home.css`. Шарится домом, магазином и PVE.

Состав: слева бренд (знак 40px + слово HEXLASH, единым кликом на дом) · справа кластер SHOP + чип кабинета. Общая высота 48px, обе стороны на одной оси.

- Панель **матовая**. Свечения на ней нет никогда.
- В магазине чип SHOP становится `← BACK`.
- На PVE слева `← BACK`, бренда нет.
- На Mode Select панели нет вообще.
- Чип кабинета — хром-ромб 28×28 **без текстового ника** (ник вернётся на Этапе 2 с кошельком).
- Баланса в панели нет (вернётся на Этапе 2).

⚠️ Правки `.hs-strip` задевают и дом, и магазин, и PVE одновременно. См. `hexlash-frontend`, §«Ловушки».

## 6. Кабинет игрока

Выезжающая панель поверх затемнённого экрана — дом для всего НЕигрового.

- Вход — **только** чип слева/справа в панели. Одна дверь.
- Выезжает справа, 392px, 420ms.
- Закрывается: крестиком · тапом по затемнению · **Esc**.
- Смонтирован всегда, открывается поверх дома и магазина.
- Повторное открытие всегда возвращает на Profile.
- **Один уровень навигации.** Внутри кабинета нет вложенных экранов.

⚠️ Кабинет **нельзя выносить через `<Teleport>`** — утечёт неправильный розовый (см. `hexlash-design/references/tokens.md`, §10).

## 7. Честные заглушки — правило SOON

Многое в игре ещё не построено. Врать интерфейсом нельзя.

**Как правильно:**
- Раздел, которого нет → честный пустой экран с подписью SOON. Матово, `#5D5D66`, без свечения.
- Режим, которого нет, но есть визуальный превью → **пускаем внутрь**, а подпись «режим скоро» ставим ВНУТРИ сцены. Игрок видит, что будет, и понимает, что играть пока нельзя.
- Кнопка-заглушка не должна выглядеть как рабочая: без розового, без свечения, без hover-жизни.

**Как неправильно:**
- Заглушка, притворяющаяся живой функцией.
- Кнопка, которая ведёт не туда, куда обещает подписью. (Известный хвост: SHOP на PVE ведёт на дом — это баг, не образец.)
- Число-заглушка без пометки, что оно ненастоящее.

## 8. Загрузка

Три тяжёлые 3D-сцены (дом / PVE / арена) **обязаны** быть прикрыты на время сборки. Игрок не должен видеть, как сцена собирается на глазах.

Два режима:

| Куда идём | Что показываем |
|-----------|----------------|
| В бой (`/play/arena`) | Полный экран «Fight Card» со счётчиком |
| Между домом / PVE / пространством | Лёгкое затемнение, фейд ~200мс |

Механика: контроллер `src/services/sceneTransition.js` + оверлей `SceneTransitionOverlay.vue` (смонтирован один раз в `AppV2.vue`). Роуты 3D-сцен помечены `meta.scene3d`, арена — `meta.arena`.

**Прогресс честный, не по таймеру.** Оверлей снимается по реальному сигналу готовности сцены: сцена эмитит `hexlash:<name>-ready` из своего первого отрисованного кадра. Страховка по времени есть, но это страховка, а не механизм.

Стиль перехода **портирован 1:1** со стиля стартового сплэша — в игре один язык загрузки, не два.

## 9. Модалки и листы

- Затемнение — `position: fixed`, перехватывает клики.
- Форма листа — срез угла (`--hs-chamfer`), HUD-уголки допустимы **внутри модалок** (с экранов они сняты).
- Закрытие: крестик · клик по затемнению · **Esc**. Все три обязательны.
- Фокус уходит внутрь модалки при открытии и возвращается на кнопку-источник при закрытии.
- Пока модалка открыта, фон не скроллится.

## 10. Скролл — усвоенные уроки

**Магазин — цельный одностраничный скролл.** Панель и контент едут вместе, одним потоком.

⚠️ **НЕ возвращать `position: sticky` и не делать flex-split со сплывающей шапкой.** Прошли 5+ заходов латания: `sticky` + `backdrop-filter` в этом контейнерном контексте дрейфует. Работает только цельный скролл.

Развязка с домом: при открытом магазине на `<body>` вешается класс `home-shop-open`; под ним в `shop.css` скроллером становится `.home-root`, а `.hs-strip` переводится в `position: relative`. `home.css` при этом **не трогается** — на доме панель по-прежнему фиксирована поверх 3D.

## 11. Текст в интерфейсе

- **Только английский.** i18n живёт, но локаль одна — `en`. Русского текста в UI нет.
- Все строки — через i18n-ключи (`src/.../en.js`), не хардкодом в шаблоне.
- Голос бренда: тихий, уверенный, без улыбок. Никаких восклицательных знаков и эмодзи в UI.
- Кнопки — глагол или короткое существительное в UPPERCASE: `FIGHT`, `BUY`, `BACK`, `EDIT SPACE`.
- Заголовки-вопросы в нижнем регистре с точкой: `Choose your mode.`, `Choose your ground.` — ключевое слово в INK `#EDEDF1`.
- Удалил элемент — **удали и его i18n-ключ**. Осиротевшие ключи копятся (известный хвост).

## 12. Доступность — минимум, который обязателен

- `focus-visible` у каждого интерактива.
- Контраст текста к фону не ниже 4.5:1 для основного, 3:1 для крупного. `#5D5D66` на `#08080A` — только для необязательной меты, не для смыслового текста.
- `prefers-reduced-motion` уважается везде (см. `hexlash-motion`).
- Иконка без подписи → `aria-label`.
- Esc закрывает всё, что открылось поверх.
- Не передавать смысл **одним только цветом**: свой/чужой, успех/ошибка должны читаться ещё и формой, позицией или подписью.

## 13. Антипаттерны

| ❌ Нельзя | ✅ Вместо |
|-----------|----------|
| `outline: none` без замены | Явное `focus-visible`-кольцо |
| Тач-зона меньше 44px | 44×44 минимум, даже если иконка мельче |
| Смысл только через hover | Всё важное читается в покое |
| Второй якорь-CTA на экране | Один FIGHT, остальное — хром |
| Розовый на вторичной кнопке | Хром-холодное свечение на касании |
| Заглушка, похожая на живую кнопку | Матовый SOON без свечения |
| Кнопка ведёт не туда, что написано | Подпись = поведение |
| `sticky`-шапка в магазине | Цельный скролл |
| Сцена собирается на глазах | Оверлей до сигнала готовности |
| Текст хардкодом в шаблоне | i18n-ключ |
| Модалка без Esc | Крестик + фон + Esc |
