# hexlash-3d — 3D-сцены

## 1. Главное правило: управляй снаружи

Боевые файлы арены и бойца **защищены**:

```
src/scene/buildArena.js       src/scene/arenaTextures.js
src/scene/arenaPresence.js    src/scene/buildFighter.js
src/scene/ArenaScene.vue      src/scene/hpIndicator.js
```

Их не правят без явного разрешения владельца в тексте задачи. Внутри — приёмленная глазами моторика и работающий бой; тихая правка ломает то, что уже одобрено.

**Паттерн проекта — управление снаружи.** Реальные примеры:

| Задача | Как решено |
|--------|-----------|
| Погасить разлом на доме | `riftGlow.opacity = 0`, `sparks off`, presence не создаётся — всё из `HomeScene.vue` |
| Убрать HP-плашку вне боя | Скан прямых детей `fighter.group` из `HomeScene.vue`; HP — единственный спрайт прямым ребёнком группы, свечение ядра вложено под торс и не задето |
| Заставить бойца ходить по дому | `homeWander.js` — режиссёр, водит **существующую** локомоцию снаружи |
| Погасить светящийся шов на полу | Обводка плиты (`THREE.Line` в `arena.group`) скрыта снаружи из `HomeScene.vue` |

Если снаружи никак — **остановись и объясни владельцу**, что придётся вскрыть защищённый файл и чем рискуем.

## 2. Сцены проекта

| Сцена | Файл | Что это |
|-------|------|---------|
| **Арена** | `ArenaScene.vue` 🔒 | Бой. Открытая плита, бойцы свободно ходят, разлом — ambient |
| **Дом** | `HomeScene.vue` | Спокойная сцена: та же плита, разлом потушен, боец бродит, лампы, пыль |
| **PVE** | `PveScene.vue` | Пространство тренировки: 5 бойцов + легенда на парящем постаменте. Только визуал |
| **Пространство** | `SpaceScene.vue` | Превью-зал: большое гекс-поле, 14 бойцов, маяк лидера. Только визуал |
| **Лаборатория** | `FighterLabScene.vue` | Дев-онли `/dev/lab`: боец на подиуме, прогон любого движения покадрово |

**Тяжёлых сцен уже четыре.** Пятую не заводить — сначала обсудить с владельцем. Принятая рекомендация: селить новое **в существующем мире** и уводить камеру, а не строить отдельную сцену.

## 3. Рецепт новой сцены

Новая сцена собирается **своими копиями** по образцу `HomeScene` / `PveScene` — не флагом внутри чужой сцены. Так дом остаётся нетронутым.

1. **Плита или поле** — база + тайленная hex-текстура в тоне арены.
2. **Купол фона** — тёмный backdrop **внутри** сцены, не CSS. Ручки `hexMaxAlpha` / `dither`; оба в `0` = ровный тёмный градиент без зерна (текущий канон для дома и PVE).
3. **Свет** — блок `LAMPS` или `LIGHT` в CONFIG. Тёплый янтарь, без теней (мобильные).
4. **Бойцы** — через `buildFighter(...)`, HP-плашки подавить снаружи.
5. **Камера** — `OrbitControls` + поляр-клампы (под плиту не заглянуть) + клампы зума + `clampPan`.
6. **Режиссёр блужданий** — своя копия `*Wander.js`.
7. **CONFIG-блоки вверху файла** — все ручки в одном месте, с комментариями.
8. **Сигнал готовности** (см. §6).
9. **Роут с `meta.scene3d`.**

## 4. Камера

- `OrbitControls` живут **только в спокойных сценах** (дом, PVE, пространство). В бою свободной камеры нет.
- Пивот: дом — грудь бойца; PVE — центр плиты; пространство — домашняя точка поля.
- Демпфирование включено. Интро-автоповорот до первого касания.
- **Клампы обязательны:** polar (не заехать под плиту, не увидеть изнанку шва), зум-коридор (дом: 3.5–12), `clampPan` (не улететь за край поля). Азимут 360° разрешён.
- Тач: one-finger вращение, pinch зум.
- **Автовозврат** (сцена пространства): отпустил → через `returnDelay` (2с) камера плавно (`returnLerp`) уезжает в зафиксированный при старте домашний ракурс; любой новый ввод прерывает возврат.

## 5. Свет и атмосфера

- Промышленные лампы-тарелки: плафон-отражатель + лампа на стержне + **реальный** `PointLight`, тёплый янтарный, приглушённый.
- **Без теней** — мобильные.
- Ядро бойца рисуется additive и постоянно → свет ламп его не перекрашивает. Это позволяет держать тёплую заливку и холодное/розовое ядро одновременно.
- Пыль: `THREE.Points` в конусе ламп, янтарь, блок `DUST`. Есть на доме; **с PVE убрана**.
- Подсвет под бойцом: блок `GLOW`, янтарь-доминанта + подмес оттенка ядра, доля 13–22% (ниже для тёплых-красных ядер, чтобы не зазвенел вторым розовым).

⚠️ **Аддитивные гало-спрайты вокруг ламп убраны** — висели пятнами в воздухе. Лампа должна читаться «горит изнутри». Не возвращать.

⚠️ В сцене пространства владелец **отклонил** возврат к объёмному лепящему свету. Ровная рассеянная заливка (Directional без теней + Hemisphere + Ambient) — окончательно.

## 6. Сигнал готовности — обязателен

Игрок не должен видеть, как сцена собирается.

Каждая 3D-сцена эмитит сигнал из **первого реально отрисованного кадра**, под per-mount латчем:

```js
window.__hex<Name>Ready = true
window.dispatchEvent(new Event('hexlash:<name>-ready'))
```

Существующие: `hexlash:arena-ready`, `hexlash:home-ready`, `hexlash:pve-ready`, `hexlash:space-ready`.

Ловят в двух местах:
- `main.js` — прямой hard-load страницы;
- `router.beforeEach` через `src/services/sceneTransition.js` — SPA-переход.

Страховка по времени есть (арена 8–12с, фейд 3с), но это **аварийный выход**, а не механизм. Прогресс честный, по вехам, не по таймеру.

## 7. Режиссёры блужданий

`homeWander.js` / `pveWander.js` / `spaceWander.js` — водят **существующую** локомоцию снаружи.

Что делает режиссёр: путь вьётся без повторов, репертуар ожидания, доворот к камере, ленивое слежение камеры, разведение агентов по полю. Всё — `CONFIG` вверху файла.

⚠️ Исторический баг: телепорт бойца при блуждании. Вылечен — если увидишь похожее, ищи в режиссёре, а не в локомоции.

## 8. Материал и визуальный закон бойца

- Огранённый low-poly, чёткие плоскости — как плита арены. Без гладких реалистичных поверхностей.
- Единая тёмная сине-серая «шкура», тот же материал, что у плит — «из одного цеха».
- **Одно светящееся ядро** на бойца, просвечивает сквозь огранку.
- Свой/чужой: у противника ядро **приглушено** (тот же оттенок, ниже яркость) + корпус чуть темнее и холоднее. **Без второго акцентного цвета.**
- Иерархия свечения на арене: ядро игрока → ядро противника → разлом как средовой ambient.
- Форма бойца может быть любой; семью держит **общий материал, не форма**.

## 9. Производительность

Целевое устройство — телефон.

- Теней нет нигде.
- Постпроцессинга нет.
- Инструмент замера — `src/scene/perfProbe.js`.
- Новая сцена проверяется **на телефоне** до мержа.
- Число бойцов в сцене — через CONFIG (`CLUB_ROSTER_COUNT` = 5, `SPACE_ROSTER_COUNT` = 14, диапазон 12–16), чтобы можно было убавить, если тормозит.
- ⚠️ Открытый хвост: сторож FPS для кинематографического перехода — вернуть.

## 10. Антипаттерны

| ❌ Нельзя | ✅ Вместо |
|-----------|----------|
| Править защищённый файл | Управлять снаружи; если никак — к владельцу |
| Переиспользовать чужую сцену флагом | Своя копия по рецепту |
| Пятая тяжёлая 3D-сцена | Селить в существующем мире, уводить камеру |
| Гало-спрайты вокруг ламп | Лампа «горит изнутри» |
| Тени | Свет без теней |
| Снятие загрузки по таймеру | Сигнал `hexlash:*-ready` |
| Камера без клампов | Polar + zoom + pan клампы |
| Магические числа в теле сцены | CONFIG-блок вверху |
| Второй акцентный цвет для «чужого» | Приглушённое ядро + холоднее корпус |
| `display:none` на WebGL-канвасе, чтобы «спрятать» сцену | Перекрыть слоем сверху (риск флэша) |
